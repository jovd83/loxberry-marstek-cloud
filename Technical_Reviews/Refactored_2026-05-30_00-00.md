## Findings Resolved

| Finding | Severity | Resolution |
|---------|----------|------------|
| MQTT connect not retried at boot | High | `MqttPublisher.__init__` now retries 3× with 5 s backoff before raising |
| Version shown in UI was `0.1.2` | Medium | `index.cgi:13` updated to `1.0.0` with sync-reminder comment |
| User-Agent hardcoded as `/0.1` | Medium | `PLUGIN_VERSION = "1.0.0"` constant added; User-Agent uses it |
| `system()` call used raw string interpolation | Medium | Replaced with `qq("$daemon" restart >>"$log" 2>&1)` — double-quoted paths |
| No CI pipeline | Medium | `.github/workflows/validate.yml` added; matches LoxBerry plugin template standard |
| `RUNNING` global mutable flag | Low | Replaced with `threading.Event` (`_shutdown`); polling sleep replaced with `_shutdown.wait(timeout=N)` — responds to SIGTERM in ≤1 s instead of spinning |
| `<script>` block mid-`<form>` | Low | Moved to just before `</form>` |
| Stale `jovd83-.*\.zip` exclusion | Low | Removed from `build_zip.py` |
